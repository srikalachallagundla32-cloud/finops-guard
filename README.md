# 🛡️ FinOps-Guard

> **Shift-Left Algorithmic Cost Protection for Cloud Infrastructure & LLM APIs**

FinOps-Guard is an open-source static analysis CLI tool written in Go. It prevents catastrophic cloud bill spikes caused by "AI slop"—sloppy, loop-bound API calls generated by AI coding assistants (e.g., OpenAI, Anthropic, AWS Athena, DynamoDB inside `for`/`while` loops).

Unlike traditional IaC tools (like Infracost) that only analyze static infrastructure configurations (Terraform/CloudFormation), **FinOps-Guard analyzes application source code logic** via Abstract Syntax Tree (AST) parsing before code is ever merged or deployed.

---

## 🚀 Core Features

- 🔍 **Static Logic Analysis:** Scans Python and TypeScript codebases to detect cloud & LLM API invocations nested within loops.
- 💰 **Dynamic Cost Engine:** Projects runtime financial exposure using real-time pricing models.
- ⚡ **Shift-Left Guardrails:** Integrates as a native pre-commit hook or GitHub Action to fail builds exceeding cost risk thresholds.
- 📊 **SARIF Output:** Native support for GitHub Code Scanning and security dashboards.

---

## 🛠️ Quick Start

### Prerequisites
- Go 1.22+

### Local Execution

```bash
# Clone repository
git clone https://github.com/<your-username>/finops-guard.git
cd finops-guard

# Run static cost analysis CLI
go run cmd/finops-guard/main.go --pricing=pricing.json
```
